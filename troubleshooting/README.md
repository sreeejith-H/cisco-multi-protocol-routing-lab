# Troubleshooting

This directory documents the routing and connectivity problems encountered during the physical lab implementation and the steps taken to resolve them.

## Issues Covered

- Incorrect IP addressing
- BGP neighbor establishment problems
- EIGRP adjacency problems
- OSPF routing issues
- Incorrect subnet configuration
- Route redistribution issues
- Missing routes
- End-to-end ping failures

## Troubleshooting Methodology

The troubleshooting process involved:

1. Checking interface status
2. Verifying IP addressing
3. Testing Layer-3 connectivity
4. Checking routing protocol neighbors
5. Inspecting the routing table
6. Identifying missing routes
7. Correcting the configuration
8. Re-testing connectivity
