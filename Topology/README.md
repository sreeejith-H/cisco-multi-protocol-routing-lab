# Network Topology

This directory contains the network topology of the Cisco multi-protocol routing lab.

The topology consists of physical Cisco 1841 routers and Cisco Catalyst C9200L multilayer switches.

## Routing Domains

- BGP AS 1980
- OSPF
- EIGRP AS 100

## Network Architecture

The topology demonstrates communication between multiple routing domains using Layer-3 routing and route redistribution.
